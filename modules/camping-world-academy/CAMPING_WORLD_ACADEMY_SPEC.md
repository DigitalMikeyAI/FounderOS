# Camping World Academy

## Status

Planning only. Not connected to the FounderOS application.

## Purpose

Create a FounderOS career-learning module that helps Michael prepare for
and continue learning during his employment at Camping World.

## Primary Goals

1. Learn the major RV categories.
2. Learn important RV terminology.
3. Learn Camping World inventory and brands.
4. Practice customer discovery conversations.
5. Store notes gathered during training and work.
6. Track learning progress over time.

## Proposed Sections

- Daily Mission
- RV Types
- RV Terminology
- Brands and Models
- Customer Discovery
- Sales Practice
- Flashcards
- Training Notes
- Progress Tracker

## Technical Boundary

This module must initially remain isolated from Mission Control.

Do not modify:

- Existing dashboard HTML
- Existing CSS
- Existing JavaScript
- Existing localStorage data
- Existing mission logic
- Existing modal logic
- Existing Archie Core logic
- Existing navigation

## Development Strategy

Phase 1: Documentation and information architecture  
Phase 2: Standalone static prototype  
Phase 3: Standalone data and storage  
Phase 4: Archie training integration  
Phase 5: Optional Mission Control navigation integration  

Integration into FounderOS requires a separate review and approval.
