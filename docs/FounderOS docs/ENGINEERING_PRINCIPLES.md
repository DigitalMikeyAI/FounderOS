**# FounderOS Engineering Principles**



Architecture over shortcuts.



Never rewrite working systems without justification.



Every feature has one owner.



Communication happens through systems, not globals.



Small migrations beat large rewrites.



Backwards compatibility is preferred.



Optimize for clarity before optimization.



The repository is the source of truth.



Every architectural decision should be explainable.

AI enhances judgment. It never replaces responsibility.

Every session produces exactly one primary decision.

Principle 8 — Separation of Intelligence

FounderOS intelligence is divided into specialized responsibilities rather than one monolithic AI. 

Reasoning determines what deserves attention.

Guidance determines how the Commander accomplishes it.

Communication determines how it is presented.

Memory preserves what has been learned.

Mission Control coordinates these systems without replacing them.
